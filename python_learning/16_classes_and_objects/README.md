# 16_classes_and_objects

Решения задач по классам и объектам: касса и черепашка. Каждая задача оформлена одним классом; в функции `main()` создается экземпляр класса и к нему применяются все методы.

## Задание 1: класс `CashRegister`

Файл: `task_01_cash_register.py`

Реализовано:
- `top_up(amount)`: пополняет кассу на указанную сумму.
- `count_1000()`: возвращает количество целых тысяч в кассе.
- `take_away(amount)`: списывает сумму или выбрасывает ошибку, если денег не хватает.

Дополнительно:
- отрицательный начальный баланс запрещен;
- суммы пополнения и списания должны быть положительными;
- при нехватке денег выбрасывается стандартная ошибка `ValueError`.

## Задание 2: класс `Turtle`

Файл: `task_02_turtle.py`

Реализовано:
- `go_up()`: увеличивает `y` на `s`;
- `go_down()`: уменьшает `y` на `s`;
- `go_left()`: уменьшает `x` на `s`;
- `go_right()`: увеличивает `x` на `s`;
- `evolve()`: увеличивает `s` на `1`;
- `degrade()`: уменьшает `s` на `1` или выбрасывает ошибку;
- `count_moves(x2, y2)`: возвращает минимальное количество ходов до точки.

В условии для `go_right()` указано увеличение `y`, но для движения вправо используется стандартная координатная логика: увеличивается `x`.
