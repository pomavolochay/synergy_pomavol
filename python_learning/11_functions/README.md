# 11_functions

Решения задач по функциям: цепочка факториалов и CRUD-база питомцев для ветеринарной клиники.

## Задание 1: факториалы

Файл: `task_01_factorial_chain.py`

Логика:
- Функция `factorial()` принимает натуральное число и возвращает его факториал.
- Для входного числа сначала считается факториал.
- Затем создается список факториалов от полученного значения до `1` в убывающем порядке.

Пример:

```text
Ввод: 3
Факториал 3: 6
Результат: [720, 120, 24, 6, 2, 1]
```

## Задание 2: CRUD-база питомцев

Файл: `task_02_pet_crud.py`

Реализованы функции:
- `create()` — добавляет новую запись и увеличивает ID на 1.
- `read()` — возвращает информацию о питомце по ID.
- `update()` — обновляет запись по ID.
- `delete()` — удаляет запись по ID.
- `get_pet()` — возвращает запись или `False`, если ID нет в базе.
- `get_suffix()` — выбирает форму `год`, `года`, `лет`.
- `pets_list()` — возвращает список строк с информацией о питомцах.

Структура базы:

```python
pets = {
    1: {
        "Мухтар": {
            "Вид питомца": "Собака",
            "Возраст питомца": 9,
            "Имя владельца": "Павел",
        },
    },
}
```

Интерактивная программа работает до команды `stop`.

Доступные команды:
- `create`
- `read`
- `update`
- `delete`
- `list`
- `stop`
