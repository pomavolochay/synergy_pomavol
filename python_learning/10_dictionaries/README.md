# 10_dictionaries

Решения задач по словарям: вложенный словарь с данными питомца и генерация словаря степеней.

## Задание 1: словарь питомца

Файл: `task_01_pet_dictionary.py`

Логика:
- Создается пустая структура `pets`, которая заполняется через `input()`.
- Ключ верхнего уровня — кличка питомца.
- Значение — вложенный словарь с видом питомца, возрастом и именем владельца.
- Возраст приводится к `int`.
- Для возраста выбирается корректная форма: `год`, `года`, `лет`.
- Итоговая строка формируется через доступ к `keys()` и `values()`.

Пример результата:

```text
Это желторотый питон по кличке "Каа". Возраст питомца: 19 лет. Имя владельца: Саша
```

## Задание 2: словарь степеней

Файл: `task_02_powers_dictionary.py`

Логика:
- С помощью цикла создается словарь для чисел от `10` до `-5` включительно.
- Ключ — само число.
- Значение — это число в степени, равной этому же числу.

Пример:

```python
{
    10: 10000000000,
    9: 387420489,
    -5: -0.00032,
}
```
