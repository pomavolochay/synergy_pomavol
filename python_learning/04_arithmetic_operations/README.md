# 04_arithmetic_operations

Решения двух задач по арифметическим операциям с упором на чистую структуру, валидацию ввода и тестируемость.

## Задание 1: площадь и периметр прямоугольника

Файл: `task_01_rectangle_metrics.py`

Что реализовано:
- Ввод двух сторон (поддержка целых и вещественных значений).
- Поддержка записи дробных чисел через запятую и точку.
- Проверка, что значения числовые и строго больше нуля.
- Вычисление площади и периметра в отдельной функции.

Формулы:
- `S = a * b`
- `P = 2 * (a + b)`

## Задание 2: вычисление по цифрам пятизначного числа

Файл: `task_02_five_digit_formula.py`

Что реализовано:
- Проверка, что введено именно пятизначное целое число (допускается знак `-`).
- Выделение нужных разрядов: десятки тысяч, тысячи, сотни, десятки, единицы.
- Расчет выражения из условия:
  - `tens ** ones`
  - результат `* hundreds`
  - результат `/ (ten_thousands - thousands)`
- Обработка случая деления на ноль.

Проверочный пример из условия:
- Для `46275` результат: `-16807.0`.
