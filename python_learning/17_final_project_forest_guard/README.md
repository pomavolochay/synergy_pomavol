# 17_final_project_forest_guard

Финальный проект: консольная игра «Лесной хранитель». Игрок управляет
вертолётом, тушит лесные пожары водой из рек, развивает технику и переживает
грозы. Поле и состояние игры отрисовываются эмодзи с механикой тиков.

## Геймплей

- Поле прямоугольное, на нём растут деревья и текут реки.
- Деревья периодически вырастают на пустых клетках.
- Пожары периодически вспыхивают на случайных деревьях.
- Если пожар вовремя не потушить, он распространяется на соседние деревья,
  а исходная клетка выгорает (`🟫`), и за это снимаются очки.
- Вертолёт берёт воду, пролетая над рекой (`🌊`), и тушит пожар (`🔥`),
  пролетая над ним с непустым резервуаром, и за это начисляются очки.
- В магазине (`🏪`) можно увеличить объём резервуара, а в госпитале (`🏥`)
  купить жизни. Взаимодействие происходит клавишей `E`.
- Погода: облака (`⬜`) и грозы (`🟥`). Под грозой вертолёт теряет жизнь.
- Когда жизни заканчиваются, игра завершается.

## Управление

| Клавиша | Действие |
|---------|----------|
| `W`/`A`/`S`/`D` | движение вертолёта |
| `E` | взаимодействие с магазином/госпиталем |
| `Z` | сохранить игру |
| `X` | загрузить игру |
| `Q` | выйти |

## Архитектура

Логика разделена на независимые модули, изолированные от ввода-вывода:

| Модуль | Ответственность |
|--------|-----------------|
| `config.py` | перечисления `Terrain`/`Weather`, глифы, баланс игры |
| `geometry.py` | значимый объект `Position` и случайные координаты |
| `world.py` | карта: генерация, рост деревьев, пожары, их распространение |
| `helicopter.py` | состояние игрока: вода, очки, жизни, покупки |
| `weather.py` | слой неба: облака и грозы |
| `persistence.py` | чтение и запись снимка игры в JSON |
| `game.py` | оркестрация тика, команды и отрисовка кадра |
| `main.py` | ввод с клавиатуры (`pynput`) и игровой цикл |

## Запуск

Установить зависимости и запустить игру из директории
`17_final_project_forest_guard`:

```bash
python -m pip install -r requirements.txt
python main.py
```

При старте игра спросит ширину и высоту поля (можно нажать Enter для значений
по умолчанию).

## Проверка тестами

```bash
python -m pytest -q
```

Тесты покрывают игровую логику без участия клавиатуры и графики: границы поля,
рост деревьев, тушение и распространение пожаров, экономику вертолёта, погоду и
сохранение/загрузку.
