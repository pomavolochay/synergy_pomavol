# 13_2d_lists

Решение задачи по двумерным спискам: генерация матриц и сложение матриц одинаковой размерности.

## Задание 1: сложение матриц

Файл: `task_01_matrix_addition.py`

Что реализовано:
- Генерация матрицы произвольной размерности через `random.randint()`.
- Проверка, что матрица прямоугольная.
- Сложение двух матриц одинаковой размерности.
- Проверка несовпадающих размеров с понятной ошибкой.
- Вывод исходных матриц и результата.

Формула сложения:

```text
matrix_3[i][j] = matrix_1[i][j] + matrix_2[i][j]
```

Алгоритм работает не только для `10x10`, но и для любых корректных размеров, например `4x3`.
